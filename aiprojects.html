Personal · 2024 – Present

I use AI as part of how I work — not just to prompt, but to actually build. These two projects started as personal problems I wanted to solve. Both are live, running in production, and I use them daily.

They show that I can think in systems, work across the full stack with AI assistance, and ship things that work — which I think is an increasingly important skill for anyone in product or marketing.

Project 01

Personal Investment Portfolio Tracker

I wanted a single view of my portfolio performance and the news that could affect it — without switching between 5 different apps. So I built one.

It pulls live market data via yfinance, fetches relevant financial news through a news API, and surfaces both in a dashboard I can check during the day to make faster, more informed decisions.

  • Live portfolio value and performance tracking across assets
  • Integrated news feed filtered to relevant tickers and market events
  • Hosted on Railway — always on, no local setup needed
  • Custom frontend built with basic HTML/CSS/JS for a clean reading experience

Project 02

Personal Expense Tracker via Line

I wanted to log expenses without switching apps — so I built a bot that lives inside Line, the messaging app I already use every day.

I can type a transaction directly in chat, assign it a category, and it gets saved to a database in real time via a webhook integration. I also built a /help command that returns a full shortcut guide inline so I never have to look anything up.

  • Log transactions via Line chat — no app switching, no friction
  • Create and manage custom expense categories and transaction names
  • /help command returns a full guide with available commands and shortcuts
  • All data stored in PostgreSQL — queryable and exportable
  • Hosted on Railway with a persistent webhook listener
